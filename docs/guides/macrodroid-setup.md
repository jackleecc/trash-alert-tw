# Android 手機中繼轉送設定指南 (臺南環保通 + MacroDroid)

本指南引導您使用隨身的 Android 手機，將官方「臺南環保通」App 的垃圾車到站推播自動轉發給我們的 LINE Bot，實現**免開電腦、免付費租伺服器、不受雲端 IP 阻擋**的零維護邊緣推播架構。

---

## 運作原理架構圖

```
[臺南環保局車隊]
       │ (車機 GPS 即時回報)
       ▼
[臺南市天眼伺服器 (clean.tnepb.gov.tw)]
       │ (透過台灣 4G/5G 原生推播)
       ▼
[您的 Android 手機]
  ├─ 1.「臺南環保通」App 收到官方到站推播
  └─ 2.「MacroDroid」自動攔截通知內容
       │
       │ (發送 HTTP POST Webhook)
       ▼
[我們的雲端後端 (/api/tainan-relay)]
  ├─ 驗證 CRON_SECRET 安全密鑰
  ├─ 30 分鐘冷卻防洗版檢核
  └─ 呼叫 LINE Messaging API
       ▼
[LINE 家人群組收到格式化到站提醒！]
```

## 第一階段：安裝與設定「臺南環保通」App

### 步驟 1-1：下載安裝
* 開啟 Google Play 商店，搜尋「**臺南環保通**」並安裝。
* （或直接點擊 [Google Play 連結](https://play.google.com/store/apps/details?id=tw.gov.tainan.epb.garbage)）。

### 步驟 1-2：設定永康區清運點與到站提醒
1. 打開「臺南環保通」App。
2. 點擊「**清運查詢**」或地圖查詢。
3. 行政區選擇「**永康區**」，清運路線選擇「**夜間31**」（或搜尋地址「**文化路40號**」）。
4. 找到該清運點後，點擊進入詳情，點選「**加入我的最愛**」或「**設定提醒**」（愛心或鈴鐺圖示）。
5. 提醒時間建議設定為「**到站前 3 分鐘**」或「**到站前 5 分鐘**」。

### 步驟 1-3：確認通知權限
* 請前往 Android 手機「設定」→「應用程式」→「臺南環保通」→「**通知**」：
  * 確認「允許通知」已開啟。
  * 確認未被設為「無聲通知」。

## 第二階段：安裝與設定「MacroDroid」自動化轉發

### 步驟 2-1：下載安裝
* 開啟 Google Play 商店，搜尋「**MacroDroid - 裝置自動化**」並安裝（免費版功能即完全足夠）。

### 步驟 2-2：授予必要系統權限
首次開啟 MacroDroid 時，請依畫面提示授予：
1. **通知存取權 (Notification Access)**：讓 MacroDroid 能讀取環保通的通知文字。
2. **略過電池最佳化 (Ignore Battery Optimization)**：避免 Android 系統在鎖定螢幕時關閉 MacroDroid。

---

### 步驟 2-3：建立自動化巨集 (Add Macro)

在 MacroDroid 首頁點擊「**新增巨集 (Add Macro)**」：

#### 1. 設定觸發器 (Triggers - 紅色區塊)
1. 點擊右上角「**+**」號。
2. 選擇「**裝置事件 (Device Events)**」→「**通知 (Notification)**」→「**通知已收到 (Notification Received)**」。
3. 選擇「**選取應用程式 (Select Application(s))**」→ 勾選「**臺南環保通**」→ 點擊確定。
4. 在文字比對畫面中，選擇「**任何 (Any)**」（或維持預設直接按確定）。

#### 2. 設定動作 (Actions - 藍色區塊)
1. 點擊右上角「**+**」號。
2. 選擇「**應用程式 (Applications)**」→「**HTTP 請求 (HTTP Request)**」。
3. 依序填入以下資訊：
   * **請求方法 (Request method)**：`POST`
   * **網址 (URL)**：
     ```
     https://<你的Vercel專案網址>/api/tainan-relay
     ```
     *(例如：`https://trash-alert-tw.vercel.app/api/tainan-relay`)*
   * **內容類型 (Content type)**：`application/json`
   * **要求標頭 (Headers)**：
     * 鍵 (Header name)：`x-cron-secret`
     * 值 (Header value)：`你的CRON_SECRET` *(與你 .env / Vercel 設定的一致)*
   * **要求內容主體 (Request Body)**：
     ```json
     {
       "title": "[not_title]",
       "text": "[not_body]",
       "secret": "你的CRON_SECRET"
     }
     ```
     *(小提示：`[not_title]` 與 `[not_body]` 可點擊輸入框旁的「...」標籤選擇 MacroDroid 內建的「通知標題」與「通知文字」動態變數)*
4. 點擊右下角勾選儲存動作。

#### 3. 設定約束條件 (Constraints - 綠色區塊，推薦選填)
為了避免平日白天收到環保宣導推播也誤觸發：
1. 點擊「**+**」號 → 選擇「**日期 / 時間 (Date/Time)**」→「**時間 (Time of Day)**」。
2. 設定範圍為 `16:30` 至 `21:00`。
3. （可選）再新增一條「**星期 (Day of Week)**」：勾選星期一、二、四、六（永康垃圾清運日）。

#### 4. 命名並啟用巨集
* 在頂部輸入巨集名稱，例如：`轉發垃圾車到站通知`。
* 點擊右下角「**儲存**」圖示。
* 確認 MacroDroid 首頁的總開關已處於「開啟」狀態。

## 第三階段：立即測試與驗證

不用等到垃圾車來，現在就可以手動測試：

1. 打開 MacroDroid，進入剛剛建立的「轉發垃圾車到站通知」巨集。
2. 點擊右上角的「**...**」（選單）→ 點選「**測試動作 (Test Actions)**」。
3. 打開 LINE 查看：
   * 您的 LINE 專案群組應該會立即收到由 LINE Bot 發送的：
     ```text
     🚛【垃圾車即將抵達提醒 (臺南環保通)】
     📍 站點：永康區文化路40號
     🛣️ 路線：永康-夜間31
     ⏰ 預估抵達：約 3～5 分鐘內
     🗺️ 站點地圖：...
     💡 來源說明：手機端「臺南環保通」車機到站即時推播
     ```
4. 若 30 分鐘內再次點擊測試動作，系統會啟動防洗版冷卻機制（阻斷重複推播），完全符合預期！

## 常見問題 (FAQ)

### Q1：隨身手機離開家裡、切換 4G/5G 或 Wi-Fi 會受影響嗎？
* **完全不會**。官方 App 的推播是由 Google 原生 FCM 系統維護，只要手機有網路（不管是中華、遠傳、台哥大或 Wi-Fi），通知都能正常收到並立即轉發。

### Q2：出國或手機沒開機時會怎麼樣？
* 若手機關機或無網路，不會發出該次到站推播；新北市（汐止）與桃園市（楊梅）的定時輪詢不受任何影響，依然由雲端 Cron 自動照常運行。

### Q3：MacroDroid 免費版會不會過期？
* MacroDroid 免費版最多允許建立 5 個巨集，我們只需使用 1 個，因此可**永久免費使用**，無需升級 Pro 版。
